# Stride — Technical & Product Decisions Log

1. **Database (`Neon Postgres 17 + PostGIS`)**: Dedicated `stride` project in `aws-ap-southeast-1` (closest region to primary India market). Pooled connection string used with HTTP serverless retry logic for scale-to-zero cold starts.
2. **Password Hashing (`PBKDF2-SHA256`, 100,000 iterations via Web Crypto)**: Fits cleanly inside Cloudflare Workers' 10 ms free-tier CPU ceiling per request with zero external WASM overhead.
3. **Map Provider Abstraction (`OpenFreeMap` Active + `Ola Maps` Fallback Ready)**: Wrapped behind `/v1/maps/config`, `/v1/maps/geocode` (24h KV cached), and `StrideMap` / `MapConfig` components. Activated OpenFreeMap (`dark` / `positron` vector styles, zero API key/card) after direct Ola Maps vector style requests returned HTTP 401.
4. **GPS Filtering & Smoothing**: Drops accuracy `> 35m` (run/walk/hike) or `> 50m` (ride), noisy initial fix jumps, non-monotonic timestamps, and teleport speed spikes; applies 3-point weighted smoothing only when turn angle `<= 25 deg`; smooths elevation with 5-point median + 3-point weighted average + `3.0m` hysteresis gain threshold.
5. **Segment Matching & Fairness**: Requires `150m <= length <= 50km`, non-closed loops (`startToEnd >= min(50m, 10% length)`), and blocks near-duplicates (`<= 40m` ends, `<= 35m` Hausdorff). Matches ordered direction with 25-point Hausdorff/Fréchet thresholds and interpolates entry/exit boundary timestamps (<1s error). Manual activities are ineligible; imported GPX files with timestamps are eligible subject to speed/gap fairness flags.
6. **Privacy & Anonymization**: New accounts default to `followers` visibility. Privacy zones and `hide_start_end_meters` strip coordinates server-side before any non-owner view or GPX export. Public city heatmap aggregates ~220m cells strictly from `visibility = 'public'` routes outside privacy zones and serves only cells with `contributor_count >= 3`.
7. **Bilingual English & Hindi (`en` + `hi`)**: Natural Indian fitness lexicon (`शाबाशी (Kudos)`, `पेस`, `सेगमेंट`, `व्यक्तिगत रिकॉर्ड (PR)`) paired with full `Noto Sans Devanagari` font support and `hreflang` alternates.
8. **Centralized UI Theme Layer**: All web tokens sit in `web/src/styles/tokens.css` and all Flutter tokens in `app/lib/theme/stride_theme.dart`, supporting Light / Dark / System mode without page-load flash.
9. **100% Cloudflare Workers Production Hosting Architecture**: Cloudflare Workers hosts the entire Stride stack on free-tier resources with zero credit card or R2 dependency:
   - `stride-api` (`https://stride-api.srimantasutapa123.workers.dev`) runs Hono TypeScript API backed by `STRIDE_KV` and Neon Postgres 17 + PostGIS 3.5.
   - `stride-web` (`https://stride-web.srimantasutapa123.workers.dev`) runs Next.js 15 SSR + static assets via `@opennextjs/cloudflare` (`1.20.18`).
   - `stride-apk` (`https://stride-apk.srimantasutapa123.workers.dev`) serves BOTH `stride-lite-android.apk` (`/lite`, `88,022` bytes / `86 KB`, SHA-256 `1b5d3869151c1a4a0a11c76824f10de8c011f95d35cfc933ddcf0feaf4ad1ea2`) and `stride-android.apk` (`/`, `25,791,329` bytes / `24.6 MB`, SHA-256 `588b1d837c45ff08aa12147b80f4f119f0f1dc30969164ddd64442064917d01b`) plus `/manifest.json` (with `run_worker_first: true` for CORS) from chunked Cloudflare Workers Static Assets (`18 MiB` parts, zero R2/card). Heatmap rebuilds are invoked via `/v1/admin/cron/heatmap` because the Cloudflare Free account quota (5 crons account-wide) is already allocated to other Workers.
10. **Cross-Origin Google OAuth Handoff (`STRIDE_KV` `?oauthCode=`)**: Because `*.workers.dev` domains sit on the Public Suffix List (preventing shared top-level domain cookies across `stride-api` and `stride-web`), Google OAuth callbacks issue a single-use short-lived `STRIDE_KV` exchange code (`POST /v1/auth/oauth-exchange`) cleanly across web, Flutter, and `Stride Lite` (`?client=lite` -> `stride-lite://oauth?oauthCode=...`).
11. **Dual Android Architecture (`Stride` Flutter 24.6 MB + `Stride Lite` Native Kotlin 86 KB)**: Removed unused `maplibre_gl` native `.so` bloat from `/app` (reducing Standard APK `86.6 MB -> 24.6 MB`, adding `AppCacheManager` 15 MB mem / 4 MB disk cap + SQLite `VACUUM`), and added `/app-lite` (`com.stride.tracker.lite`) built directly on Android SDK APIs + SQLite + R8 shrinking (`88,022` bytes) with configurable `512 KB / 2 MB / 5 MB` LRU cache caps, `PRAGMA auto_vacuum = FULL`, `Data Saver`, and auto-purge temp sweep.
