# Design Inspire — 100% Creative & Asset Freedom

- **Zero Rigid Templates**: Any files in `design-inspire/` are strictly optional mood/craft inspiration—never copy fixed layouts or treat them as templates.
- **100% God-Mode Authority**: Judge existing code or base drafts ruthlessly. Keep what works, or tear down and rewrite weak/boring layouts from scratch.
- **Full Media & Engineering Flex**: Use high-res photography (Unsplash, curated visuals), custom SVGs, videos, WebGL/GLSL shaders, 3D canvas scenes, smooth scroll storytelling, and physics-driven micro-interactions.
- **Clean Desktop Proportions (`1440px–1920px`)**: Keep typography, cards, and spacing crisp, balanced, and properly scaled—never comically huge.
